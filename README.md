# Rushilo releases

Installers for [Rushilo](https://rushilo.com), the local desktop video and image editor driven by your own AI.

Download the latest version from [Releases](https://github.com/rushilohq/rushilo-releases/releases/latest):

- **Mac:** the `.dmg` for your Mac (`arm64` for Apple silicon, `x64` for Intel)
- **Windows:** the `.exe` installer

Installed copies of Rushilo update themselves from this repo. The source code is private.
